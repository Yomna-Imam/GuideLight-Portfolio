GuideLight

Overview

GuideLight is a voice-based mobile application designed to improve accessibility for visually impaired users. The app helps users understand official documents, receive spoken guidance, and access important information independently.

Features

- Upload official documents for analysis.
- AI-powered document understanding.
- Voice explanations of document content.
- Identifies the required destination, appointment time, and necessary documents.
- Voice-guided navigation to the destination.
- Provides the location on a map.
- Can recommend or direct users to specialized support when needed.
- Accessibility-focused interface for visually impaired users.

Technologies

- Thunkable
- AI-powered document analysis
- Voice guidance
- Location and Maps services

Purpose

GuideLight was created to make official services more accessible for visually impaired individuals by simplifying document understanding and providing clear voice guidance from start to finish.

Target Users

- Visually impaired users.
- Anyone who needs assistance understanding official documents and navigating to service locations.
